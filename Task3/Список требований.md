## Список требований, которым должны удовлетворять внешние интеграции.
### Требования к безопасности:
- Использование межсетевого экрана для ограничения входящего и исходящего трафика
- Использование аутентификации и авторизации, например, OAuth 2.0
- Использование HTTPS шифрования при взаимодействии
- Применение принципа наименьших привилегий при выдаче прав собственникам
- Разграничить доступ к домофону и шлагбауму - собственники должны иметь доступ только к домофону своего подъезда и шлагбауму своего двора (ABAC)
- Проводить периодический аудит прав доступа, ведите логи действий пользователей
- Логирование процесса взаимодействия с Умным домом
- Аудирование событий, значимых для информационной безопасности,
- Маскирование персональных и других чувствительных данных при логировании и аудите 
- Подключение SIEM системы для автоматического выявления аномалий в реальном времени и оповещения
- По возможности исключить передачу персональных данных и другой конфиденциальной информации между системами, обезличивание персональных данных

### Протоколы аутентификации и авторизации
- OAuth 2.1
- Все данные передаются по HTTPS (протокол TLS>=1.2)
- При передаче персональных данных использовать протоколы, соответствующие требованиям 152 ФЗ 

### Как будет организовано взаимодействие между системами предприятия и внешней платформой.
Сервис tenant-core-app содержит таблицу с домофонами и шлагбаумами с привязкой к подъезду и дому.
Собственник заходит в приложение и исходя из того, какими квартирами владеет, видит определенный
список домофонов и шлагбаумов которыми он может управлять.
Нажимает в UI кнопку "открыть дверь подъезда", tenant-core-app идет в Сервер авторизации,
получает jwt токен, с этим токеном выполняет запрос в Умный дом. Умный дом проверяет валидность
токена, если токен валидный и достаточно прав на выполнение операции, то Умный дом отправляет 
датчику команду на открытие двери.
Каждое обращение к Умному дому логируется и аудируется. С помощью SIEM отслеживаются подозрительные
активности (например, более 5 неудачных попыток аутентификации подряд).
